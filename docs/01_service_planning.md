# 01. 서비스 기획 문서

## 1. 서비스 정의

### 서비스명

**이음(IEUM): 국가유산 AI 해설 서비스**

### 한 줄 소개

사용자의 언어, 이용 상황, 관심 카테고리에 따라 국가유산 해설과 다음 추천을 이어주는 AI 기반 국가유산 해설·추천 서비스입니다.

### 핵심 컨셉

이음은 국가유산 정보를 단순히 보여주는 서비스가 아닙니다.  
사용자가 실제 현장에 있는지, 다른 장소에서 탐색 중인지, 어떤 관점으로 이해하고 싶은지에 따라 해설의 관점과 다음 탐색 흐름을 다르게 제공합니다.

```txt
언어 선택
→ 현장 방문 / 비현장 탐색 선택
→ 유산 선택
→ 관심 카테고리 선택
→ 공식 자료 기반 AI 해설
→ 텍스트 + TTS + 공식 이미지 제공
→ 다음 유산 추천
→ 관련 K-콘텐츠 추천
```

## 2. 문제 정의

### 핵심 문제

국가유산 정보는 이미 존재하지만, 사용자의 현재 상황과 관심사에 맞춰 무엇을 보고, 어떤 관점으로 이해하고, 다음에 무엇을 탐색할지 이어주는 개인화된 디지털 해설 경험은 부족합니다.

### 세부 문제

| 문제 | 설명 |
| --- | --- |
| 해설 경로 부족 | 방문 이후 무엇을 먼저 보고 어떤 순서로 이해할지 안내받기 어려움 |
| 고정형 해설 | 같은 설명이 모든 사용자에게 동일하게 제공되는 경우가 많음 |
| 언어·이해 접근성 한계 | 다국어 안내가 있더라도 사용자의 문화적 배경과 이해 수준에 따른 설명 전환이 제한적 |
| 다음 탐색 연결 부족 | 하나의 유산 설명 이후 관련 유산, 주제, 콘텐츠로 이어지는 흐름 부족 |
| AI 신뢰성 문제 | 공식 근거 없이 생성형 AI가 역사 정보를 답할 경우 오류와 환각 위험 존재 |

### 한 줄 문제 정의

문제는 정보 부족이 아니라, 사용자 맥락에 맞춰 이어지는 해설 흐름의 부족입니다.

## 3. 해결 방향

### 3-1. 이용 상황 기반 흐름 분기

| 모드 | 사용자 상황 | 제공 방식 |
| --- | --- | --- |
| 현장 방문 모드 | 궁궐, 박물관, 유적지 등 실제 장소에 있는 사용자 | 현재 위치 또는 주변 유산 목록을 기준으로 해설 대상 추천 |
| 비현장 탐색 모드 | 다른 장소에서 국가유산을 탐색하는 사용자 | 검색 또는 추천 목록을 통해 관심 유산 선택 후 해설 제공 |

### 3-2. 관심 카테고리 기반 해설

사용자는 해설을 듣기 전에 관심 카테고리를 선택합니다.  
AI는 같은 국가유산이라도 선택한 카테고리에 따라 설명 관점을 바꿉니다.

| 카테고리 | 해설 방향 |
| --- | --- |
| 역사 | 시대 흐름, 사건, 변화 과정 중심 |
| 건축 | 공간 배치, 구조, 공법, 관찰 포인트 중심 |
| 예술·상징 | 문양, 색채, 장식, 상징 의미 중심 |
| 왕실문화 | 의례, 왕실 생활, 궁중 문화 중심 |
| 종교·제례 | 불교, 유교, 제례, 신앙적 의미 중심 |
| 세계유산 | 탁월한 보편적 가치와 국제적 의미 중심 |
| 과학·기술 | 천문, 음향, 제작 기술, 보존과학 중심 |
| 생활문화 | 의식주, 지역 생활, 민속, 일상 문화 중심 |

### 3-3. 정보 제공 방식

| 제공 방식 | 설명 |
| --- | --- |
| 텍스트 해설 | 공식 근거를 바탕으로 사용자가 이해하기 쉬운 문장으로 제공 |
| TTS 음성 | 현장 관람 중 화면을 오래 보지 않아도 들을 수 있도록 제공 |
| 공식 이미지 | 공식 이미지와 출처를 우선 표시 |
| 심화 해설 | 관심을 보인 사용자가 더 깊게 탐색할 수 있는 세부 카드 제공 |
| 비교 해설 | 유사한 시대·양식·재료·상징을 가진 유산과 비교 |
| 다음 추천 | 해설 이후 관련 유산과 콘텐츠로 탐색 확장 |

## 4. 사용자 시나리오

### 시나리오 A. 경복궁 현장 방문자

```txt
사용자가 경복궁에 도착
→ 한국어 선택
→ 현장 방문 모드 선택
→ 주변 유산 목록에서 근정전 선택
→ 관심 카테고리: 건축 선택
→ 공식 자료 기반 RAG 검색
→ 근정전의 건축 구조와 상징을 텍스트 + TTS로 제공
→ 창덕궁 인정전, 종묘 등 관련 유산 추천
```

### 시나리오 B. 비현장 탐색 사용자

```txt
사용자가 다른 장소에서 비현장 탐색 모드 선택
→ 검색으로 첨성대 선택
→ 관심 카테고리: 과학·기술 선택
→ 첨성대의 천문 관측 의미와 구조적 특징 해설
→ 석굴암, 불국사, 신라 과학·기술 관련 유산 추천
→ 관련 다큐·영상 콘텐츠 추천
```

### 시나리오 C. 외국인 관광객

```txt
사용자가 영어 선택
→ 현장 방문 모드 선택
→ 국립중앙박물관 또는 주변 유산 선택
→ 관심 카테고리: 예술·상징 선택
→ 어려운 한국사 용어를 문화적 맥락과 함께 쉬운 영어로 설명
→ 출처와 핵심 키워드 확인
→ 주변 유산 또는 관련 전시 추천
```

## 5. 기대효과

| 관점 | 기대효과 |
| --- | --- |
| 사용자 | 관심사와 이해 수준에 맞춘 국가유산 해설 경험 제공 |
| 외국인 관광객 | 단순 번역을 넘어 문화적 맥락까지 이해할 수 있는 다국어 해설 가능 |
| 문화기관 | 공식 자료를 기반으로 한 디지털 해설 활용 가능성 확장 |
| 지역 관광 | 하나의 유산 감상이 주변 유산과 지역 콘텐츠 탐색으로 이어짐 |
| 교육 | 학생·가족 대상 쉬운 해설과 탐방 학습으로 확장 가능 |
| 기술 | RAG와 출처 표시 기반의 신뢰 가능한 문화유산 AI 활용 사례 제시 |

## 6. MVP와 확장 구분

### MVP

- 언어 선택
- 현장 / 비현장 선택
- 유산 선택
- 관심 카테고리 선택
- 공식 자료 기반 RAG 해설
- 텍스트 + TTS + 공식 이미지 제공
- 카테고리·키워드 기반 다음 유산 추천
- 관심 카테고리 기반 기본 K-콘텐츠 추천

### 확장

- AI 참고 시각화
- Graph DB 기반 추천 고도화
- 행동 로그 기반 프로파일링
- 리워드 / 랭킹
- K-콘텐츠 추천 고도화
- Multi-Persona 해설
