# 03. MVP 및 프로토타입 문서

## 1. 문서 목적

이 문서는 이음의 MVP 구현 범위와 Figma Prototype 흐름을 정리하기 위한 문서입니다.

핵심 기준은 다음입니다.

```txt
많은 기능을 얕게 넣기보다,
국가유산 AI 해설 서비스에서 가장 중요한 정확성, 개인화, 현장 사용성, 다음 탐색 연결성에 집중한다.
```

## 2. MVP 핵심 흐름

```txt
앱 실행
→ 언어 선택
→ 현장 방문 / 비현장 탐색 선택
→ 유산 선택
→ 관심 카테고리 선택
→ 공식 자료 기반 AI 해설 생성
→ 텍스트 + TTS + 공식 이미지 제공
→ 심화 / 비교 해설 선택
→ 다음 유산 추천
→ 관심 기반 K-콘텐츠 추천
→ 탐방 기록 및 리워드 확장
```

## 3. MVP 포함 기능

### 3-1. 온보딩

첫 진입에서 서비스 가치를 전달합니다.

### 3-2. 언어 선택

사용자가 해설을 제공받을 언어를 선택합니다.

지원 후보:

- 한국어
- 영어
- 일본어
- 중국어 간체 / 번체

### 3-3. 이용 장소 선택

| 모드 | 설명 |
| --- | --- |
| 현장 방문 모드 | 사용자가 실제 장소에 있을 때 주변 유산 또는 현재 장소 중심으로 해설 |
| 비현장 탐색 모드 | 다른 장소에서 관심 있는 유산을 검색하고 해설 |

### 3-4. 유산 검색 / 선택

- 주변 유산 목록
- 유산명 검색
- 지역별 필터
- 대표 이미지와 위치 정보 표시
- 유산 기본 정보 확인

### 3-5. 관심 카테고리 선택

| 카테고리 | 설명 |
| --- | --- |
| 역사 | 시대 흐름, 사건, 변화 과정 중심 |
| 건축 | 공간 배치, 구조, 공법, 관찰 포인트 중심 |
| 예술·상징 | 문양, 색채, 장식, 상징 의미 중심 |
| 왕실문화 | 의례, 왕실 생활, 궁중 문화 중심 |
| 종교·제례 | 불교, 유교, 제례, 신앙적 의미 중심 |
| 세계유산 | 탁월한 보편적 가치와 국제적 의미 중심 |
| 과학·기술 | 천문, 음향, 제작 기술, 보존과학 중심 |
| 생활문화 | 의식주, 지역 생활, 민속, 일상 문화 중심 |

### 3-6. AI 맞춤 해설 화면

주요 UI 요소:

- 상단 대표 이미지
- 유산명 / 지역 / 관심 카테고리 배지
- AI 해설 카드
- TTS 플레이어
- 출처 보기 버튼
- 심화 해설 보기
- 비교 해설 보기
- 다음 추천 보기

### 3-7. 다음 유산 추천

MVP에서는 규칙 기반 추천 또는 간단한 유사도 추천을 우선 적용합니다.

### 3-8. K-콘텐츠 추천

사용자가 유산 추천 흐름을 종료하면 관심 카테고리 기반으로 관련 콘텐츠를 추천합니다.

### 3-9. 마이페이지 / 기록

기록 기능은 탐방 경험을 정리하는 보조 기능입니다. 리워드와 랭킹은 확장 기능으로 분리합니다.

## 4. Figma Prototype 흐름

```txt
시작하기
→ 언어 선택
→ 이용 장소 선택
→ 유산 검색 / 선택
→ 관심 카테고리 선택
→ AI 해설
→ 심화 / 비교 해설
→ 다음 유산 추천
→ K-콘텐츠 추천
→ 마이페이지 / 기록
```

## 5. Prototype 버튼 연결 기준

| 버튼 | 이동 화면 |
| --- | --- |
| 시작하기 | 언어 선택 화면 |
| 언어 선택 완료 | 이용 장소 선택 |
| 현장 방문 중 | 주변 유산 목록 |
| 비현장 탐색 | 문화유산 검색 |
| 문화유산 카드 | 관심 카테고리 선택 |
| 해설 시작하기 | AI 맞춤 해설 화면 |
| 심화 해설 보기 | 심화 해설 화면 |
| 비교 해설 보기 | 비교 해설 화면 |
| 다음 추천 보기 | 다음 유산 추천 화면 |
| 해설 종료하기 | K-콘텐츠 추천 화면 |
| K-콘텐츠 확인 완료 | 마이페이지 / 마무리 |

| Multi-Persona 해설 | 확장 기능 |
| 정교한 지도 / 경계 polygon 표시 | 확장 기능 |
